# Measurement Data

The original frequency-response workbook and source plot were used during development but are not included in this public starter package.

Before redistributing those materials, confirm the original source's terms and obtain any required permission. The CC BY 4.0 license in this repository does not apply to third-party measurement data or target curves.

A future release may include:
- measurement data that the project owner has permission to redistribute;
- clearly documented measurement conditions and source attribution;
- reproducible plots generated from redistributable data.
