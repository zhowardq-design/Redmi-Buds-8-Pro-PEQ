# 1812 Overture Cannon-Effect Test

The user supplied a FLAC recording described as containing cannon sound effects associated with the Deems Taylor commentary/sound-effects track. The requested analysis window was the first five seconds. The user indicated that the first three cannon sounds are the effects later used in the CD track.

The recording itself is not included in this repository because it may be copyrighted. This directory is reserved for reproducible analysis artifacts (plots, scripts, numerical summaries) that can be shared lawfully.

## Listening observation
With V2-A, the listener reported a more convincing perception of an explosive core expanding outward, followed by a larger but less dense sound field.

## Caution
Any frequency-band energy figures or waveform measurements should be accompanied by the exact time windows, channel-combination method, windowing, normalization, and analysis script. Do not treat normalized band-energy percentages as acoustic SPL or as proof of earphone performance.
