# 《1812 序曲》炮声效果测试

用户提供了一段 FLAC 录音，据描述，其中包含 Deems Taylor 讲解/音效音轨中的炮声效果。分析要求关注开头五秒。用户指出，最初的三声炮声就是后来在 CD 曲目中使用的音效。

由于录音可能受版权保护，仓库不包含该录音文件。本目录用于存放可以合法分享、并可供重复验证的分析资料（图表、脚本、数值摘要）。

## 试听记录

使用 V2-A 时，试听者认为爆炸核心向外扩散的听感更加可信，随后形成一个范围更大、但声音密度较低的声场。

## 注意事项

任何频段能量数据或波形测量结果，都应同时说明准确的时间窗口、声道合并方法、窗函数、归一化方式及分析脚本。不要将归一化后的频段能量百分比视为声压级（SPL），也不要将其作为耳机性能的证明。
