# Redmi Buds 8 Pro – PEQ 调音项目

这是一个面向社区的 Redmi Buds 8 Pro 参数均衡器（PEQ）配置与测量基础调音记录项目。

**Language / 语言：** [English](README.md)

> **项目状态：** V1 是基于测量数据拟合的基准配置。V2-A 是在 V1 基础上进行低频调整、并经过试听评估的版本。目前，项目维护者在 Redmi K-Pad + Redmi Buds 8 Pro + Poweramp 的使用组合中，将 V2-A 作为默认 PEQ。V2-A 属于个人试听调整，并非小米/Redmi 官方产品或官方配置。

## V2-A 的调整内容

V2-A 只修改了滤波器 1–7 的增益值。滤波器类型、中心频率、Q 值、滤波器 8–32，以及 Preamp 均与 V1 保持一致。

| 滤波器 | 类型 | 频率 | V1 增益 | V2-A 增益 | 变化 |
|---:|---|---:|---:|---:|---:|
| 1 | Low Shelf | 35 Hz | -2.10 dB | -1.60 dB | +0.50 dB |
| 2 | Peaking | 38.0 Hz | -1.44 dB | -0.64 dB | +0.80 dB |
| 3 | Peaking | 45.6 Hz | -1.74 dB | -0.94 dB | +0.80 dB |
| 4 | Peaking | 54.7 Hz | -2.28 dB | -1.48 dB | +0.80 dB |
| 5 | Peaking | 65.6 Hz | -2.37 dB | -1.57 dB | +0.80 dB |
| 6 | Peaking | 78.7 Hz | -1.98 dB | -1.18 dB | +0.80 dB |
| 7 | Peaking | 94.3 Hz | -1.31 dB | -0.51 dB | +0.80 dB |

此次调整的起因，是试听了与柴可夫斯基《1812 序曲》相关录音中的开场炮声效果。最初的主观试听记录认为，V2-A 呈现出更明确、紧凑的爆炸核心，并有向外扩散、衰减时声音密度逐渐降低的听感。这是主观听感记录，并非对空间准确性的客观测量。

## 测量与调音依据

- 基准配置使用项目开发过程中采用的 192 kHz 测量数据，拟合 ReaLab Target Response (2024)。
- 滤波器结构：1 个 Low Shelf + 31 个 Peaking。
- 拟合频率范围：20 Hz–9 kHz；9 kHz 以上不进行补偿。
- 源工作簿报告的模型拟合 RMSE 为 0.174 dB。这是模型对目标修正曲线的数值拟合误差，**不是**真实佩戴状态下的频响测量误差，也不代表主观音质保证。
- V2-A 并非重新拟合目标曲线，而是在 V1 基础上进行的试听调整版本。

开发过程中使用过辅助频响测量资料，但由于尚未确认其再发布许可，本仓库暂不分发这些源测量资料。详见[测量数据说明](measurements/README.zh-CN.md)。

## 使用方法

1. 下载所需的 `.txt` 配置文件。
2. 在兼容的参数均衡器应用程序（例如 Poweramp Equalizer）中导入配置，或手动输入滤波器参数。
3. 确认应用程序将 `LSC` 识别为 Low Shelf，将 `PK` 识别为 Peaking。
4. 使用配置文件中标示的 Preamp 数值。
5. 音量、耳塞套密封情况、佩戴方式、固件、编解码器及播放处理均可能影响实际听感。

文本配置采用易读的 AutoEQ/Poweramp 风格滤波器记法。不同版本应用程序的兼容性可能有所差异。

## 重要限制

- PEQ 改变的是音频信号的频率响应，不能提高耳机单元的物理振膜位移能力，也不能提高其无明显失真的最大输出能力。
- 数字滤波器仿真不能预测耳机在实际耳道中的声学输出、失真、内部 DSP 或动态限幅行为。
- 配置名称中的 192 kHz 指生成配置时所使用的测量数据，并不意味着蓝牙以 192 kHz 传输音频。
- 实际结果可能因个人耳型、耳塞套、听力、固件、音源设备和聆听音量而异。
- 避免过大的聆听音量。增加低频增益可能提高单元振幅和失真。
